1.  line-height
    => 줄 높이를 설정하는 css 속성입니다.
    => 단위 없이 숫자만 지정하면 해당 요소의 font-size의 n배입니다. -> 1.5라면 font-size의 1.5배


2. text-decorator
    => 대부분 요소의 default value -> none입니다.
    => a tag는 text-decorator : underline -> 현대적이지 않습니다. none으로 바꿉니다.


3. inherit
    => css 속성의 값으로 inherit를 받으면 부모나 조상의 값을 그대로 사용하겠다는 의미입니다.


4. position
    4-1. static
        => 기본적인 문서 흐름(block, inline)에 맞춰 요소들을 배치합니다.
    
    4-2. relative
        => 원래 위치를 기준으로 top, bottom, right, left가 동작합니다.
        => 다른 요소들이 relative가 적용된 위치를 무시하지 않습니다.
    
    4-3. absolute
        => 가장 가까운 조상의 position 값을 가진 요소를 기준으로 top, bottom, right, left가 동작합니다.
        => 다른 요소들이 absolute가 적용된 위치를 무시합니다.
    
    4-4. fixed / sticky
        => 어려움 / 뭔가 고정된 상태
    

5. z-index
    => 요소가 겹쳤을 때 무엇을 우선적으로 보여줄지 값을 받아서 정합니다.
    => default 0 / 높은 값을 우선합니다.


6. transition
    => transition : 속성, 시간, 곡선
    => transition에 기재된 속성이 변경될 떄 시간과 곡선에 맞춰서 변경됩니다.


7. header.scrolled
    => js가 변경되면서 이를 추가해서 변화됩니다.


8. 작은 화면을 css를 먼저 작성하는 흐름


9. 모바일 nav 속성
    => flex, flex row -> 가로 배치
    => align-items -> 가로 배치에서 세로 중앙 배치
    => justify-content : center -> 가로 배치에서 서로의 간격이 일정해야 하고 양 끝은 붙어있음

10. 모바일 nav-menu action
    => 요소 클릭하면 js에 의해 클래스 붙음
    => flex, flex-col -> 세로 배치
    => position : absolute -> 가까운 조상 -> nav -> relative
    => top : 100% -> 부모 100% 다음에 위치, 바로 다음에 위치
    => left, rigjt : 0 -> 쭉 늘어남

11. 모바일 nav-meni li
    => width : 100%차지


12. opacity
    => 투명도를 의미합니다.
    => 1이면 다 보이고 0이면 투명합니다.

13. transform : translateY(30px)
    => 원래 위치보다 아래쪽으로 30px 이동하라


14. section:not(#home)
    => section이고 id가 home이 아닌 전부를 선택
    => 투명도를 0으로 하고 trnasform으로 위치를 내림

15. section:not(#home).visible
    => section이고 id가 home이 아니고 visble 클래스인 전부를 선택
    => 투명도를 1으로 하고 trnasform으로 정상 위치로 이동하라
