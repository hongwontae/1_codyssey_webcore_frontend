** 요소와 속성 **
    => 태그를 요소라고하고 태그 내부의 부가 정보를 속성이라고 합니다.

1. <head>
    => 브라우저에게 이 웹페이지에 대한 정보를 제공하는 영역입니다.
    => 웹 페이지의 설정/정보를 제공하는 영역 태그입니다.

2. <meta>
    2-1. 웹페이지 자체에 대한 메타데이터(metadata)를 브라우저 등에 알려주는 태그입니다.
    2-2. <meta charset="UTF-8">
        => VS Code가 홍원태라는 문자들을 UTF-8이라는 인코딩 규칙을 사용해서 바이트로 변환
        => html 파일 내부에는 바이트 데이터가 존재
        => 이러한 바이트 데이트를 보고 바로 홍원태라고 해석 가능 -> 불가능, 인코딩 규칙을 알아야 합니다.
        => 브라우저에게 utf-8이라는 방식으로 해석해야 됨을 알려줘야 함 -> 그게 2-2 meta가 하는 일입니다.
        => 이제 브라우저가 utf-8 인코딩 규칙을 발견하면 html에 존재하는 문자 바이트들을 utf-8 방식으로 해석합니다.

    2-3. <meta name="viewport" content="width=device-width, initial-scale=1.0">
        => viewport란 현재 웹페이지를 볼 수 있는 브라우저 영역입니다.
        => content="width=device-width"은 veiewport의 너비를 device의 너비로 설정하라는 의미입니다.
        => 즉, 기기 화면 너비가 viewport의 너비가 됩니다.
        => 스마트폰 - viewport width ≈ 375px / 태블릿 - viewport width ≈ 768px / 노트북 - viewport width ≈ 1440px
        => initial-scale=1.0 -> 페이지를 처음 열었을 떄 본 확대 배율을 100%로 설정합니다.
    
3. <title>
    => 브라우저 탭 이름을 정하는 태그입니다.

4. <link>
    => HTML 문서와 외부 리소스를 연결하는 태그입니다.
    => href -> 연결할 리소스 위치를 나타냅니다.
    => rel="stylesheet" -> 링크된 리소스가 현재 html 문서와 어떤 관계인지 알려줍니다.

5. <script>
    => js 코드를 html 문서에 포함하거나 외부 js 파일을 연결해서 실행하도록 하는 태그입니다.
    => js 코드 html 문서 포함 or js 파일 연결 실행 -> 둘 중 하나만 해야 합니다. 둘 다 하면 파일 연결만 실행됩니다.


6. <!DOCTYPE html>
    => DOCTYPE 선언(문서 형식 선언)입니다.
    => 브라우저에게 해당 문서는 html 5라고 알려주는 것입니다.
    => 과거에는 여러가지 방식으로 html 해석 -> 브라우저에게 html 5라고 알려줘야 제대로 해석합니다.

7. <html lang="ko">
    => html 태그는 문서 전체를 감싸는 치상위 요소입니다.
    => html 문서의 주된 언어는 한국어라고 알려주는 태그입니다.
    => 스크린 리더, 검색엔진, 프로그램이 문서의 언어를 이해할 떄 도움이 됩니다.
    => lang이라는 속성은 일반 태그에 사용되어 해당 태그만 영어 언어라는 정보를 줄 수 있습니다.
