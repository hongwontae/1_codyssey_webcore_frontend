1. 서버에서 브라우저로 HTML 파일이 전달됩니다.
    => 브라우저가 html을 파싱하기 시작합니다.

2. <head>를 읽습니다.
    => utf=8, viewport, title.. 메타 태그들을 파싱합니다.

3. <link>를 읽습니다.
    => 브라우저가 html에 css 파일이 연결되었음을 확인합니다.
    => 이제 css 파일을 읽고 css 규칙을 해석합니다.
    => 이 떄 브라우저가 css 파일을 다운로드하고 파싱해서 cssom을 만들떄까지 html 파싱을 멈추는 것이 아닙니다. 각자 진행합니다.
    => 다만 렌더링 단계에서는 css가 준비되어야 합니다. -> cssom 필요

4. <script>를 읽습니다.
    => defer를 사용하면 js 파일 자체를 다운로드 하지만 실행하지 않습니다.
    => html 파싱 종료 후 js를 실행합니다.
    => js 코드는 html 태그를 target하는 코드가 존재하는데 js를 먼저 실행해버리면 원하는 동작이 실패할 수 있습니다.
    => 만약 script 태그에 src 속성을 제외한 아무런 속성이 없다면 script 태그를 만나면 html 파싱 중단 -> js 다운로드 -> js 실행 -> html 파싱 재개 순으로 이어집니다.
    => 만약 script 태그에 async 속성 -> js 다운로드를 html 파싱과 동시에 진행하되 다운로드가 끝나는 즉시 실행합니다. -> js 실행동안 html 파싱 일시 중지
    => 즉, defer나 asnyc나 js 다운로드와 html 파싱은 동시에 진행되지만 defer는 파싱 후, async는 js 다운로드 완료되면 바로 실행

5. body를 읽어서 dom으로 만듭니다.

6. html + css가 만나서 화면을 계산합니다.
    => dom + cssom

7. html 파싱 종료
    => 이제 js를 실행합니다.
