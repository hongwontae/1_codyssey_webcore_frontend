1. document.querySelector()
    => 조건에 맞는 HTML 요소 하나를 찾아오는 JS 함수입니다.
    => 이 때 인자에 CSS 선택자를 사용합니다.
    => document.querySelector("CSS 선택자")
    <h1>Hello</h1>                   const h1 = document.querySelector("h1");
    <p class="text">안녕하세요</p>      const text = document.querySelector(".text");
    <p class="text">반갑습니다</p>      const p = document.querySelector("p");
    => 이 때 반환값은 HTML 요소 객체입니다.
    => 찾을 수 없다면 null를 반환합니다.


2. document.querySelectorAll()
    => 조건에 맞는 HTML 요소 전부를 찾아오는 JS 함수입니다.
    => 이 떄 인자에 CSS 선택자를 사용합니다.
    => 이 떄 반환값은 배열이 아니라 NodeList 입니다.


3. HTML 요소 객체
    => 브라우저는 HTML을 읽으면서 JS에서 다룰 수 있는 객체로 만들어 놓습니다. -> 이게 DOM 입니다.
    => 즉, DOM 요소를 나타내는 객체를 의미합니다.
    => 요소 객체에는 요소의 정보(.id, .class, .textContent) /요소의 기능 (.addEventListener, .remove, .disabled..)
    => 즉, 요소 객체를 얻고 요소의 정보를 읽거나 요소를 조작합니다.


4. projects-list : div

7. projects-empty : p
8. projects-retry : button


9. 요소객체.style
    => 그 요소의 인라인 CSS 스타일을 다루는 객체입니다.
    => div.style.display = 'none';
    => 해당 요소의 display css에 값을 none를 준다는 의미입니다.
    => css 파일 수정이 아니라 인라인 스타일 적용입니다.


10. 요소객체.textContent
    => 요소 객체의 text를 수정하는 속성입니다.
    => text에 html 태그를 주면 무시합니다.
    => 현재 innerHTML에 텍스트만 주는 코드가 있어서 textContent로 수정


11. 요소객체.innerHTML
    => 요소 객체 내부의 text 자리에 HTML를 수정하는 속성입니다.


12. display = "none"
    => 해당 요소를 완전히 제거하는 것입니다.
    => visibility : hidden -> 안보이지만 공간를 차지합니다.
    => display = "none" -> 안보이고 공간도 없습니다.


13. 처음에는 fetchProjects()를 호출합니다.
    => 첫 번쨰로 showLoading를 호출합니다.
    => 로딩 요소 block / 에러 요소 none / empty 요소 none / list요소.textContent = ''
    => try-catch 안에서 fetch를 실행합니다.
    => fetch가 http를 요청했을 때 서버가 404/500을 응답해도 catch로 보내지 않습니다. -> not found, internal sever error

    => JS로 변환 값 중 fork라는 키가 있습니다. -> GitHub에서 어떤 저장소를 다른 사람의 계정으로 복사해서 가져오는 것입니다.

    => filter를 통해서 false라면 true로 만들고 그 값만 정제해서 가져옵니다.

    => 그리고 그 배열의 길이가 0이라면 showEmpty()를 실행하고 return 합니다.
    => loaidng : "none", error : "none", empty : "block", list.textContent : "";


14. addEventListener
    => JS에서 HTML 요소에서 특정 이벤트가 발생했을 때 실행할 코드를 등록하는 것입니다.
    => 요소.addEventListener("이벤트", 함수);
    => 이벤트란 웹 페이지에서 어떤 사건이 발생했다는 사실입니다.
    => 브라우저가 사용자 행동을 감지하고, 그 결과를 이벤트로 만들어 DOM의 해당 요소와 연결해서 전달합니다. (행동 자체를 감지하는 주체는 브라우저)
             사용자
               │
            버튼 클릭
               ↓
          ┌──────────┐
          │ 브라우저  │  ← 실제 행동을 감지
          └────┬─────┘
               │
          click 이벤트 생성
               ↓
          ┌──────────┐
          │   DOM    │  ← 어떤 요소에서 발생했는지 연결
          │  button  │
          └────┬─────┘
               │
       등록된 이벤트 리스너
               ↓
          JavaScript 함수
