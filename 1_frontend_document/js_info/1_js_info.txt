1. document.querySelector()
    => 조건에 맞는 HTML 요소 하나를 찾아오는 JS 함수입니다.
    => 이 때 인자에 CSS 선택자를 사용합니다.
    => document.querySelector("CSS 선택자")
    <h1>Hello</h1>                   const h1 = document.querySelector("h1");
    <p class="text">안녕하세요</p>      const text = document.querySelector(".text");
    <p class="text">반갑습니다</p>      const p = document.querySelector("p");
    => 이 때 반환값은 HTML 요소 객체입니다.
    => 찾을 수 없다면 null를 반환합니다.


2. document.querySelectorAll()
    => 조건에 맞는 HTML 요소 전부를 찾아오는 JS 함수입니다.
    => 이 떄 인자에 CSS 선택자를 사용합니다.
    => 이 떄 반환값은 배열이 아니라 NodeList 입니다.


3. HTML 요소 객체
    => 브라우저는 HTML을 읽으면서 JS에서 다룰 수 있는 객체로 만들어 놓습니다. -> 이게 DOM 입니다.
    => 즉, DOM 요소를 나타내는 객체를 의미합니다.
    => 요소 객체에는 요소의 정보(.id, .class, .textContent) /요소의 기능 (.addEventListener, .remove, .disabled..)
    => 즉, 요소 객체를 얻고 요소의 정보를 읽거나 요소를 조작합니다.


4. projects-list : div

9. 요소객체.style
    => 그 요소의 인라인 CSS 스타일을 다루는 객체입니다.
    => div.style.display = 'none';
    => 해당 요소의 display css에 값을 none를 준다는 의미입니다.
    => css 파일 수정이 아니라 인라인 스타일 적용입니다.


10. 요소객체.textContent
    => 요소 객체의 text를 수정하는 속성입니다.
    => text에 html 태그를 주면 무시합니다.
    => 현재 innerHTML에 텍스트만 주는 코드가 있어서 textContent로 수정


11. 요소객체.innerHTML
    => 요소 객체 내부의 text 자리에 HTML를 수정하는 속성입니다.
