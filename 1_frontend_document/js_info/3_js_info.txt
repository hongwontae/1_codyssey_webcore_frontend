4. const observer = new IntersectionObserver(  
        (entries) => {
            entries.forEach((entry) => {

                if (entry.isIntersecting) {
                    entry.target.classList.add('visible');
                } else {
                    entry.target.classList.remove(
                        'visible'
                    );}
            });

        }, {threshold: 0.2}
    );
    => IntersectionObserver는 해당 HTML이 들어왔는지 감시해달라고 요청하는 객체입니다.
    => new IntersectionObserver는 새로운 감시자를 만듭니다.
    => 감시자에게 감지됐을 떄 실행할 함수, 감지 조건을 인자로 받습니다.
    => entires는 감지 결과가 배열로 들어옵니다. ->  각 entry는 특정 요소 하나에 대한 관찰 결과 객체입니다.
    => entry
        ├─ target
        │    └─ 감시하고 있는 실제 HTML 요소
        │
        ├─ isIntersecting
        │    └─ 현재 화면에 들어와 있는가?
        │
        ├─ intersectionRatio
        │    └─ 얼마나 화면에 들어와 있는가?
        │
        └─ ...
    => entry.isIntersecting -> 현재 요소가 화면에 겹쳐 있는가? boolean
    => entry.target -> 지금 감시하고 있는 실제 html 요소 -> dom
    => {threshold: 0.2} 감시하는 요소의 20%가 화면에 들어왔을 때 IntersectionObserver의 상태 변화를 감지하겠다.

6. form.addEventListener('submit', (event) => {

    event.preventDefault();

    successMessage.textContent = '';

    const isValid = validateForm();

    if (!isValid) {
        return;
    }
    successMessage.textContent =
        '문의가 성공적으로 제출되었습니다.';

    form.reset();

});
    => html 기본 동작을 막습니다.
    => ValidateForm()을 실행합니다.
    => 그 결과 true 라면 그 다음
    => textContent 성공 메시지로 변경
    => 그리고 form reset
